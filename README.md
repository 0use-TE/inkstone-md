# 墨页 Markdown 0.4.4 · Android 预览版

## 本次：下拉菜单重做

- 右上角 ⋮ 仍是**锚定在按钮上的下拉菜单**，不是底部面板。
- 下拉面板**距离屏幕右侧留 12dp 间距**，不再贴着边缘。
- 面板会按屏幕边界自动夹取位置：左右都不越界；下方空间不足时**自动向上翻转**，不会被裁切。
- 文档长按弹出的菜单同样使用这套下拉面板：显示文档名、导出为文件、重命名、删除（删除为红色警示色）。
- 面板样式扁平：白底、细描边、小圆角、按压有波纹，无阴影卡片。

## 本次：入口再收敛 + 文档可删除

- 侧栏头部只剩标题，不再放新建、导入和大纲折叠。
- **新建、打开/导入回到右上角菜单**，和导出、另存为等放在一起。
- **长按任意文档**弹出上下文菜单：导出为文件、重命名、删除。
- 新增删除能力：只删除本机副本，已导出的 .md 文件不受影响；删除前有确认，删掉当前文档会自动切到下一篇，删空则新建空白文档。
- 大纲的分支折叠仍可用节点箭头逐个折叠。

## 本次：操作入口按职责分散 + 扁平化界面

**入口重新分工**，不再把所有操作堆在右上角：

| 位置 | 操作 |
| --- | --- |
| 侧栏「文档」页头部 | 新建、导入 |
| 侧栏「文档」列表每行 | 导出（把这篇写成 .md 文件） |
| 侧栏「大纲」页头部 | 全部展开、全部折叠、定位当前章节 |
| 底部 | 书写 / 源码 / 分栏 |
| 右上 ⋮ | 导出文件、另存为、重命名、插入图片、切换模式、格式工具栏、帮助、开源许可 |

菜单文案也一并精简：不再出现“保存 / 导出为文件”“重命名本机文档”这类长句。

**扁平化**：去掉按钮的填充块与圆角卡片，改用纯文字 + 按压透明度；当前章节不再用色块，靠左侧竖条和文字颜色表示；页签用下划线而非底色块。

**帮助面板**重写为分组的短句（文档 / 大纲与模式 / 快捷键），不再是一整段流水账。

## 本次：大纲改成树形

大纲不再是按级别缩进的大块文字，而是接近 Typora 的树形结构：

- 真正的层级：按标题实际归属嵌套，跳级标题也不会错位；左侧有层级引导线。
- 可折叠：有子标题的节点带箭头，点击折叠/展开，仅隐藏子孙，不隐藏自身。
- 当前章节高亮：随光标或滚动位置自动跟随，左侧竖条加浅色底纹标记当前所在章节。
- 紧凑排版：每行 38dp、单行省略、层级用细引导线而不是大块留白。
- 折叠状态按文档分别记忆；“⋯”菜单提供全部展开、全部折叠、定位当前章节。
- 键盘可达：方向键在层级间移动，←/→ 折叠或展开，Enter 跳转。

## 本次修复与图标

- Ctrl+0 修正为真正的“标题还原正文”：书写模式使用标题命令 level=0；源码/分栏对所选标题执行单次可撤销的文本修改，兼容 ATX H1–H6 与 Setext 下划线标题，不修改代码围栏中的伪标题。
- 修复源码/分栏撤销重做误用 CodeMirror 的分支；当前编辑器实际使用 ProseMirror。
- 格式快捷键只在正文获得焦点时生效；长按按键不会落入第二套键位重复执行。
- 新图标：深松绿底、象牙白与鼠尾草纸页、负形钢笔尖。包含 Android 自适应图标和 Android 13+ 单色主题图标。
- 图标源文件在 `artwork/icon.svg`，预览为 `artwork/inkstone-icon-512.png` 和 `artwork/inkstone-icon-1024.png`。安装测试依赖后运行 `node artwork/render-icon.cjs` 可重绘。

参考 Typora 的“侧栏 + 文档 + 菜单”写作结构，原生 Android 文档库配合内置 WebView 富文本编辑核心。不是 Typora 复刻。

## 三种编辑模式

底部切换，或用菜单 / 快捷键：

| 模式 | 说明 |
| --- | --- |
| 书写 | 所见即所得，边写边排版 |
| 源码 | 纯 Markdown 源码编辑 |
| 分栏 | 左侧源码，右侧实时预览 |

源码与分栏共用同一个实时编辑器，切换不会丢失光标位置和撤销历史。

## 键盘快捷键

外接键盘可用；格式命令在当前模式不支持时不会静默失败，会给出提示。

| 快捷键 | 作用 |
| --- | --- |
| Ctrl+1 ～ Ctrl+6 | 设为一级到六级标题 |
| Ctrl+0 | 取消标题，恢复正文 |
| Ctrl+B / Ctrl+I | 加粗 / 斜体 |
| Ctrl+Shift+X | 删除线 |
| Ctrl+Shift+C | 代码块 |

| Ctrl+Z / Ctrl+Shift+Z、Ctrl+Y | 撤销 / 重做 |
| Ctrl+Shift+I | 打开图片选择器 |

## 界面与操作

- 顶部只保留侧栏按钮、当前文档标题和 `⋮` 菜单。
- 新建、打开/导入、保存到文件、另存为、重命名、插入图片都收进菜单。
- 格式工具栏默认隐藏，可在菜单显隐。
- 左侧“文档 / 大纲”双页：文档列表显示标题和摘要，可按名称搜索、点击切换。
- 大纲显示 Markdown H1–H6 的树形层级，点击跳转；支持 ATX 和 Setext 标题，排除代码围栏内伪标题。
- 平板宽屏默认左右并排，可收起；窄屏使用侧栏抽屉。
- 新文档可根据标题自动命名，也可从菜单手动改名；长按当前文档标题同样可改名。
- 界面不显示保存状态、存储位置等提示文字；保存与导出只在菜单中体现。


## 多文档与保存逻辑

每篇文档在 App 私有文档库里独立保存。输入后约 700ms 自动保存；切换、新建、导入和正常返回退出前，会先抓取当前内容并等待本机保存成功，失败则不继续切换。

- **本机自动保存**：保留多篇文档，重新打开 App 后仍在。
- **保存到文件 / 另存为**：通过系统文件选择器写入你选定的外部 `.md` 文件。
- 自动保存本机副本不会悄悄改写外部文件；保存到外部文件需主动执行菜单里的保存。界面不再显示常驻保存状态文字。
- 再次打开同一个已导入 URI 会切回本机副本，不用外部文件覆盖当前本机修改。暂不做外部文件监视、目录同步或冲突合并。
- 重命名只修改本机列表名称，不改动外部文件名。
- 此版本不提供删除文档操作，避免误删；重要内容仍应定期导出。

0.1.0 升级时，若存在旧的单篇草稿，会迁移为文档库的第一篇并保留原旧草稿文件；已有文档库时不重复迁移。使用同签名覆盖安装，不应卸载或清除数据。

**卸载或清除应用数据会删除本机文档库；它不是系统文件备份服务。** 不会主动删除已经导出的外部文件。异常杀进程可能丢失最后约 700ms 尚未提交的输入。

## 编辑、图片和快捷键

支持标题、列表、任务、引用、表格、链接和代码块；书写/Markdown 源码切换。Markdown 富文本转换可能规范化空白和部分语法，首次编辑重要内容建议另存副本，不承诺完整 Typora 语法或逐字节往返。

图片通过菜单“插入图片”选择，也保留系统分享图片入口。不再突出或承诺 Ctrl+V 图片与输入法图片兼容；文字粘贴走 WebView 标准行为。

图片最长边缩至 1600 像素并内嵌为 data URI，单个 `.md` 可以携带图片，但部分阅读器不支持；暂不解析相对路径附件目录。动图经原生导入会变静态，暂未处理所有 EXIF 方向场景。文档上限 20 MiB，原始图片上限 32 MiB，压缩后图片上限 6 MiB。

- 快捷键：Ctrl+N 新建、Ctrl+O 打开、Ctrl+S 保存、Ctrl+Shift+S 另存为。

## 离线与安全

无 INTERNET、全量相册或所有文件访问权限。不上传内容；远程图片不加载，外部链接由用户确认后交给浏览器。CSP 禁止内联脚本与网络连接，Markdown HTML 使用 DOMPurify 3.3.0 净化；JavaScript bridge 仅用于内置页面。

多文档 bridge 带文档 ID，切换时取消旧文档的定时回调，拒绝旧文档晚到的自动保存/大纲/图片事件。文档库文本按独立 UUID 文件原子替换；元数据损坏不会隐藏尚存的文本文件。

## 本机构建与测试

```sh
cp local.properties.example local.properties   # 填入自己的 SDK 路径
cd /root/workspace/inkstone-md
bash build-debug.sh :app:testDebugUnitTest --offline
bash verify-apk.sh
node --test tests/editor.test.cjs tests/outline.test.cjs tests/paragraph-reset.test.cjs
node tests/runtime/smoke.cjs
```

`local.properties` 含本机绝对路径，已加入 `.gitignore`，不随仓库分发；首次克隆请从 `local.properties.example` 复制。`build-debug.sh` 也写死了本机工具链路径，换机器需要调整。

DOM 测试依赖首次可用 `cd tests/runtime && npm ci --ignore-scripts --no-audit --no-fund` 安装。测试不替代 Android 触控与文件提供器的实机验收。

沿用 Ubuntu ARM64 OpenJDK17、Gradle8.9、AGP8.7.3、Kotlin2.0.21、SDK34 和原生 ARM64 AAPT2。构建脚本与 local.properties 是本机路径，换机器需调整。APK 输出为 `app/build/outputs/apk/debug/app-debug.apk`，使用调试签名，供测试。
