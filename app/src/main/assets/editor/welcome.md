# 写下此刻的想法

欢迎来到 **墨页**。把注意力留给文字，把工具收进菜单。

> 让文字保持简单，让想法自然生长。

## 一处写作，多篇文档

点击左上角 **☰** 打开侧栏：

- **文档**：浏览、搜索、切换多篇 Markdown
- **大纲**：查看当前文档的层级，点击标题跳转

平板会把侧栏与正文并排显示；小屏幕则按需展开。

## 新建与文件操作

侧栏顶部 **＋** 可以新建文档。右上角 **⋮** 按 **文件 / 编辑 / 格式 / 视图** 分类；宽屏会在顶部直接显示菜单。

**文件** 提供新建、打开、保存、另存为和重命名。**编辑** 提供撤销、重做、查找与替换。**格式** 提供标题、列表、链接、图片和表格。

在系统文件管理器打开 Markdown 时，选择 **墨页** 并设为 **始终**，即可用它阅读文档。不同文件管理器是否提供“始终”选项，以系统为准。

底部 **书写 / 源码** 标出当前模式。书写时直接输入 Markdown，光标所在的格式范围显示标记，其他位置显示排版。未选中文字按 **Ctrl+B** 会插入一对 `**`，光标在中间，输入后直接加粗。

进入 **源码** 后可以选择 **仅源码 / 分栏预览 / 仅预览**。**视图** 菜单还提供只读、专注、打字机和格式工具栏开关。

在 **视图 → 主题** 中选择 **跟随系统 / 浅色 / 深色**。默认跟随系统，选择会自动记住；切换主题不影响正在编辑的内容和撤销历史。

### 本机保存与文件导出

每篇文档都会独立自动保存在本机。新建、切换不会覆盖其他文档，重新打开也能继续写。

要获得外部 `.md` 文件，请在菜单中选择 **保存到文件** 或 **另存为**。本机自动保存不等于同步外部文件。

**重要：卸载或清除 App 数据会删除本机文档库，请定期导出重要文章。**
