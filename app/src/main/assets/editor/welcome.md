# 写下此刻的想法

欢迎来到 **墨页**。把注意力留给文字，把工具收进菜单。

> 让文字保持简单，让想法自然生长。

## 一处写作，多篇文档

点击左上角 **☰** 打开侧栏：

- **文档**：浏览、搜索、切换多篇 Markdown
- **大纲**：查看当前文档的层级，点击标题跳转

平板会把侧栏与正文并排显示；小屏幕则按需展开。

## 操作都在菜单里

右上角 **⋮** 提供新建、打开、保存、另存为、重命名和插图。

格式工具栏默认隐藏，需要时在菜单里打开。底部可以切换 **书写 / 源码**。

### 本机保存与文件导出

每篇文档都会独立自动保存在本机。新建、切换不会覆盖其他文档，重新打开也能继续写。

要获得外部 `.md` 文件，请在菜单中选择 **保存到文件** 或 **另存为**。本机自动保存不等于同步外部文件。

**重要：卸载或清除 App 数据会删除本机文档库，请定期导出重要文章。**
